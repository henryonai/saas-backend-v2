# Plans

One folder per change, `YYMMDD-HHMM-slug/plan.md`, written before the code and frozen once it
lands. A plan says why the change is built this way and what was ruled out. How the system works
today is in the README files, which change with the code.

Deferred work lives in [`BACKLOG.md`](BACKLOG.md). The ship kit plans, builds and lands these
changes (`ship state` lists them); this repo's profile is [`.ship/profile.yaml`](../.ship/profile.yaml).
